# Вагон-ресторан АО «ФПК»

Интерактивный фронтенд-прототип автономной системы заказов для поездов «Аврора» и «Буревестник».

Публичная версия: <https://tatyanababenkova.github.io/rest/>

## Что можно показать

- пассажир оформляет несколько заказов со стола №4;
- официант подтверждает заказ пассажира или быстро создаёт заказ для любого из четырёх столов;
- позиции автоматически разделяются между кухней и баром;
- кухня и бар ведут собственные очереди и отмечают готовность;
- официант видит общий статус и отмечает подачу;
- менеджер переключает стили «Аврора» / «Буревестник», режим подтверждения и стоп-лист;
- состояние сохраняется только в текущем браузере и сбрасывается кнопкой менеджера.

## Меню

Основной справочник находится в `data/menu.xlsx`. При публикации GitHub Actions запускает `tools/sync_menu_from_excel.py` и обновляет JSON, который читает сайт. Скрипт использует только стандартную библиотеку Python.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте <http://localhost:3000/>.
